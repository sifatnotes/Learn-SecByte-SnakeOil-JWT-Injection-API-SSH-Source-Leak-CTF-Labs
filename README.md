## Introduction

The SnakeOil collection provides practical exercises covering application reconnaissance, authentication, secrets discovery, source-code exposure, injection, API enumeration, and JWT-related security concepts.

The labs can be approached progressively, beginning with application discovery and secrets hunting before moving into injection, hidden endpoints, and authentication-focused exercises.

Use these resources only in authorized training environments.

## Learning Path

A practical progression is:

1. Start with **SnakeOil Startup** to understand the application environment.
2. Explore **SnakeOil Endpoint Hunt** and **Hidden APIs Snake Oil Hunt** for application and API discovery.
3. Continue with **SnakeOil Secrets** and **SnakeOil SSH Secrets** for secrets-related investigation.
4. Study **SnakeOil Source Leak** to understand the security impact of exposed source code.
5. Move into **Flask JWT SnakeOil** for application authentication concepts.
6. Practice JWT-focused investigation with **JWT Secret Hunt** and **SnakeOil JWT Breakout**.
7. Finish with **SnakeOil Command Trap**, **Snake-Oil Injection**, and **SnakeOil Injection Lab** for injection-security practice.

## How to Use the Labs

1. Choose a lab from the direct-link index.
2. Confirm that the target is an authorized training environment.
3. Read the objectives and establish the testing scope.
4. Begin with reconnaissance and application discovery.
5. Document endpoints, parameters, technologies, authentication mechanisms, and exposed information.
6. Test security weaknesses only against the permitted target.
7. Record your methodology and findings.
8. Review secure development and defensive mitigations after each exercise.
